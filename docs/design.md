# Incline — first working version

Approved direction: a short pairwise visual quiz that captures multiple design preferences, project context, and willingness to explore. A profile is evidence, not a single personality type.

## Scope
Eight comparisons, including controlled attribute comparisons and a spacing follow-up selected from an earlier response. Choices: A, B, both, neither, depends. Optional reasons accompany each answer. Three project contexts use consistent content within each pair. Previous answers can be revised; dependent follow-ups are discarded and recalculated.

Results retain positive, relative, negative, and conditional evidence separately. Losing a comparison never becomes a dislike. Different styles coexist; one project's answers never overwrite another's. Users explicitly mark directions to keep or explore and write preservation notes. Confidence remains provisional: this quiz is not validated preference research.

Device-local storage with a clear notice, separate project sessions, editable results, and Markdown/JSON exports. No accounts, model training, external transmission of answers, or automatic skill rewriting. Exported records remain available for a later learning system.

## Visual direction
An editorial workbench: crisp ink typography, cool white surfaces, lime accents, a visible comparison canvas, and restrained chrome. Actual interface specimens use identical content within each pair. Mobile stacks the candidates, with both available before choosing.

## Validation
Unit tests protect multi-style preservation, loser semantics, context isolation, unknown answers, adaptive follow-ups, backtracking, storage validation, and export semantics. Type checking, lint, production build and an HTTP smoke check validate delivery. Browser interaction testing is outside the current requested scope.
