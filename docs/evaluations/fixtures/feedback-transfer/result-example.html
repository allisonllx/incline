The filter covers rows 1–2 and columns 1–2.

Stride 1 · no padding · one input channel. A 3 × 3 input with a 2 × 2 filter gives a 2 × 2 output. This filter is unchanged by a 180° flip, so convolution and the unflipped operation commonly used in neural networks give the same result here.

What changed?

The filter adds the top-left and bottom-right values in each window. Its zero weights ignore the other two values. Moving the filter changes the input values, while the weights stay fixed.
